Avito Assistant Web UI (ASP.NET Core 8, C-Sharp)
================================================

Веб-интерфейс для демонстрации ИИ-помощника покупателя на защите проекта
Хакатон ЮФУ (20–22 ноября 2026), Кейс Avito Start
Связанный репозиторий ядра: ../Avito-Assistent/README.md

Интерактивное веб-приложение для демонстрации работы интеллектуального помощника покупателя. Подключено напрямую к библиотеке ядра BuyerAssistant.Core и полностью повторяет логику контрактного CLI-сервиса run.


Возможности веб-интерфейса
--------------------------

1. Интерактивный диалог с помощником (Вкладка Чат):
   - Поддержка многошаговых диалогов с сохранением контекста.
   - Карточки подобранных комплектов (статус ok) с подсчетом общей стоимости, остатка от бюджета и ссылками на подробности каждого товара.
   - Отображение карточек уточнения (статус clarify) при нехватке параметров.
   - Информативные объяснения причин (статус no_match) с расчетом минимальной стоимости комплекта в городе.
   - Быстрые подсказки для тестирования типовых сценариев в один клик.

2. Боковая панель «Извлеченные условия» и живой лог:
   - Показывает в реальном времени, как модель google/gemma-4-31B-it распарсила реплику: распознанный город, бюджет, категории, ключевые слова и точные операторы ограничений (width_cm <= 100, adjustable_height == true).
   - Живой лог конвейера обработки (stderr).

3. Витрина каталога объявлений (Меню Инструменты -> Витрина):
   - Просмотр всех 111 товаров из базы данных data/catalog.json.
   - Мгновенная фильтрация по городу (Таганрог, Ростов-на-Дону, Азов), категории (Стол, Кресло, Лампа) и текстовый поиск по названию или ID.
   - Кэширование каталога с автоматической инвалидацией по SHA-256 при обновлении файла.

4. Инспектор строгого контракта (Меню Инструменты -> Инспектор контракта):
   - Инструмент для прямого тестирования эндпоинта POST /api/contract.
   - Принимает сырой JSON по схеме schemas/request.schema.json и возвращает ответ строго по schemas/response.schema.json без элементов UI.


Запуск на Windows
-----------------

Способ 1. В 1 клик (Рекомендуемый):
Просто дважды кликните по файлу start-web.cmd в папке проекта.
Скрипт запустит сервер и автоматически откроет страницу в браузере: http://localhost:5000

Способ 2. Через консоль (PowerShell / CMD):
cd c:\Users\Pavel\Desktop\Avito-Assistent-Web
dotnet run

Или прямой запуск скомпилированного бинарника (достаточно только .NET Runtime):
.\bin\Release\net8.0\BuyerAssistant.Web.exe


Запуск на Linux (Ubuntu, Debian, RHEL)
--------------------------------------

Способ 1. Запуск через dotnet CLI (если установлен .NET 8, 9 или 10):
```sh
cd Avito-Assistent-Web
dotnet run
```
Или прямой запуск скомпилированной библиотеки:
```sh
dotnet bin/Release/net8.0/BuyerAssistant.Web.dll
```

Способ 2. Запуск с переопределением порта и каталога:
```sh
PORT=8080 CATALOG_PATH=../Avito-Assistent/data/catalog.json dotnet bin/Release/net8.0/BuyerAssistant.Web.dll
```

Способ 3. Автономная сборка под Linux (без установки dotnet на сервере):
Собрать полностью автономный однофайловый веб-сервер под linux-x64:
```sh
dotnet publish BuyerAssistant.Web.csproj -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true -p:DebugType=none -o bin-linux
chmod +x bin-linux/BuyerAssistant.Web
./bin-linux/BuyerAssistant.Web
```

Способ 4. Фоновый запуск сервиса (демон):
```sh
nohup dotnet bin/Release/net8.0/BuyerAssistant.Web.dll > web.log 2>&1 &
```

Проверка доступности сервера в терминале Linux:
```sh
curl -s http://localhost:5000/api/health
```


Переменные окружения
--------------------

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| PORT | TCP-порт веб-сервера | 5000 (слушает на всех интерфейсах 0.0.0.0) |
| CATALOG_PATH | Путь к файлу каталога catalog.json | ../Avito-Assistent/data/catalog.json |
| LLM_BASE_URL | URL шлюза модели организаторов | Считывается из окружения или .env |
| LLM_MODEL | Модель для разбора | google/gemma-4-31B-it |
| LLM_API_KEY | Токен авторизации (Bearer) | Считывается из окружения или .env |
| LLM_USER_AGENT | Заголовок User-Agent | team-01/1.0 |
| LLM_FALLBACK | Резервный парсер при сбоях LLM | 1 (включен) |


HTTP API эндпоинты
------------------

- GET /api/health: статус сервиса, путь к каталогу, проверка доступности настроек LLM и флага fallback.
- GET /api/catalog: список объявлений с параметрами фильтрации city_id и category.
- POST /api/chat: эндпоинт для Web UI (возвращает контрактный ответ, карточки товаров, диагностику условий и лог выполнения).
- POST /api/contract: строгий контрактный эндпоинт по CONTRACT.md.
